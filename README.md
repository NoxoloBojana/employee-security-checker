# Employee Security Checker

## What is this project?

The Employee Security Checker is a simple project that checks basic employee security information.

The idea is to help a company make sure that employees are following basic security rules.

## Why do we need it?

Companies have important information about their employees and customers.

If employees do not follow security rules, company information could be at risk.

This project helps check simple things like:

* Employee username
* Password security
* Whether the employee has completed security training
* Whether the employee's account is active

## How does it work?

The program takes employee information and checks it against simple security rules.

For example:

1. The employee enters their information.
2. The program checks the information.
3. The program gives a result.
4. The company can see if the employee passes or needs to improve their security.

## Example

An employee might have:

* Username: Noxolo
* Strong password: Yes
* Security training completed: Yes
* Account active: Yes

The result could be:

**Security Status: PASS **

If an employee does not meet the requirements, the program could show:

**Security Status: NEEDS ATTENTION **
